# MangaKindle

Берёт ссылку на мангу с mangalib.me, скачивает главы, режет развороты,
приводит страницы под экран Kindle 11th gen (1072×1448, 300 ppi, серый)
и собирает готовый файл.

Личный инструмент для чтения на своём устройстве. Ничего не публикует,
никуда не раздаёт, защиту сайта не обходит.

## Что уже работает (этап 1)

Командная строка: ссылка → PDF или EPUB. GUI, отправка на Kindle
по USB и по почте — следующие этапы.

## Установка

Нужен [uv](https://docs.astral.sh/uv/). Python 3.13 он поставит сам.

```bash
git clone <репозиторий> mangakindle
cd mangakindle
uv sync
```

## Запуск

Посмотреть список глав:

```bash
uv run mangakindle "https://mangalib.me/ru/manga/1357--vagabond" --list
```

Собрать первую главу в PDF (по умолчанию — в `~/MangaKindle`):

```bash
uv run mangakindle "https://mangalib.me/ru/manga/1357--vagabond" --chapters 1
```

Главы 1–10 одним томом в EPUB:

```bash
uv run mangakindle "https://mangalib.me/ru/manga/1357--vagabond" --chapters 1-10 --volume --format epub
```

Если глава на сайте закрыта — сохрани страницы сам и собери из папки или архива:

```bash
uv run mangakindle --local ~/Загрузки/глава_5 --chapters 1
```

### Ключи

| Ключ | Что делает |
|---|---|
| `--chapters` | `all`, `3`, `1-10`, `1,4,7-9` |
| `--volume` | выбранные главы одним файлом вместо файла на главу |
| `--format` | `pdf` (для USB), `epub` (для почты), `cbz` |
| `--direction` | `rtl` — манга (по умолчанию), `ltr` — манхва и маньхуа |
| `--spread` | `split` — резать развороты пополам, `rotate`, `keep` |
| `--no-trim` | не обрезать поля страниц |
| `--quality` | качество JPEG, по умолчанию 85 |
| `--delay` | пауза между запросами, по умолчанию 0.7 сек |
| `--keep-cache` | не удалять скачанные страницы после сборки |
| `--out` | папка для готовых файлов |

## Почему PDF для USB, а не EPUB

EPUB, скопированный в `documents/` по USB, Kindle не открывает: поддержка
EPUB есть только в Send to Kindle, где файл конвертируется на стороне Amazon.
Поэтому по USB — PDF со страницами ровно 1072×1448, он рендерится нативно
и на весь экран. Для почты — EPUB fixed-layout с чтением справа налево.

## Как это ходит на сайт

Только публичный JSON-API mangalib, без логина и без обхода капчи.
Между запросами пауза 0.7 сек, один поток, User-Agent — имя приложения.
Картинкам сайт требует заголовок `Referer` (защита от хотлинка) — он
отправляется, больше ничего не подменяется.

Если тайтл 18+ или главы сняты по требованию правообладателя, приложение
честно скажет об этом и остановится. На такой случай есть `--local`.

## Где что лежит

- настройки: `~/.config/mangakindle/config.toml`
- кэш страниц: `~/.cache/mangakindle/` (чистится после сборки)
- готовые файлы: `~/MangaKindle/`
